# Task Manager Project Requirements

## Project Description
The Task Manager is a simple web application that helps users organize and manage their daily tasks.

## Main Requirements
- Users can add new tasks
- Users can delete tasks
- Users can assign deadlines to tasks
- Users can search for tasks
- The system should provide a simple and user-friendly interface

## Project Goal
The goal of this project is to help users track their tasks in an organized and simple way.
